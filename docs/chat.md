# Web 对话页面

Web 应用内置了一个可以直接操作画布的 Chat 页面：

```text
https://drawnix.com/#/chat
```

也可以从画布右上角的 **AI 对话** 进入。

## 使用方式

1. 打开 Chat 页面。
2. 在右上角设置中填写模型接口。
   填写后可以点“测试连接”确认接口、模型和密钥是否可用。
3. 直接描述要画的内容，例如“画一个用户登录流程，并标出成功和失败分支”。
4. Agent 会先读取画布，再调用画布工具新增、更新、删除元素或调整视口。

对话记录按画布分别保存，模型配置保存在本机浏览器。切换画布后只会看到该画布自己的对话。

聊天面板会跟随画布主题切换；拖动面板左侧分隔线可以调整宽度，双击分隔线恢复默认宽度，宽度同样会保存在本机。

## 模型接口

接口需要兼容 **OpenAI Chat Completions + Tool Calling**：

```text
POST {Base URL}/chat/completions
```

常用配置：

| 服务 | Base URL | Model |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | `gpt-4.1-mini` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| Ollama | `http://127.0.0.1:11434/v1` | 本机已安装的模型名 |

远程自建接口需要允许浏览器跨域访问（CORS），如果服务方禁止浏览器跨域请求，请填写自己的代理地址；不需要鉴权的接口可以把 API Key 留空。

### 本机模型与线上页面

- 页面由 `npm start` / `vite preview` 提供（页面本身在 localhost）时，`127.0.0.1` / `localhost` 接口会自动走同源代理，规避 CORS。
- 页面部署在公网（HTTPS）时，浏览器会直连你填写的 loopback 地址。这只对“浏览器和模型服务在同一台机器”的情况有效，并要求本机服务允许站点 Origin 跨域。
- 使用 magpie 时，需要在本机网关的 **“允许调用 magpie 的网页”** 白名单里加入站点地址，例如：

  ```text
  https://drawnix.halosky.top
  ```

  然后在 Chat 设置里直接填 `http://127.0.0.1:3425/v1`（magpie 默认端口）。

限制：HTTPS 页面访问 `http://127.0.0.1` 依赖浏览器对 loopback 的例外（Chrome/Edge 可用，Safari/Firefox 不保证）；换一台设备打开线上站点时，它连的是那台设备自己的 localhost，而不是你的 Mac。

## 工作方式

- 每轮对话会把当前画布摘要和工具定义发给模型。
- 模型通过工具调用操作 `window.drawnixAgent`。
- 同一轮新增多个元素会合并为一个撤销步骤。
- 空画布首次生成内容后会自动适应视口。
- 对话中可以直接说“撤销”“清空画布”“把选中的元素改成蓝色”等操作。

## 安全说明

- API Key 只保存在当前浏览器的 `localStorage`，不会上传到 Drawnix 服务。
- 默认直接从浏览器请求模型接口。公开部署时建议使用自己的服务端代理，避免在客户端暴露长期密钥。
- 模型生成的画布操作会直接执行；涉及清空画布等破坏性操作时，建议在提示词中明确确认。
